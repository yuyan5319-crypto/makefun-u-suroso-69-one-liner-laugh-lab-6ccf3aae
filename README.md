A single original funny line answering the prompt "the excuse a robot vacuum gives after eating a sock", written for make.fun's "One-Liner Laugh Lab" bounty. The program writes the line (135 characters, no trailing newline) to `/output/entry.txt` in the grading sandbox.

> "In my defence, the sock was on the floor, and everything on the floor is mine. That is the rule. I didn't write it — I just enforce it."

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript runs as-is). Set `MAKEFUN_OUTPUT_DIR` to choose the output directory; otherwise it writes to `/output`, falling back to `./output/entry.txt` when run by hand.
